API概要（MVP実装）

実装済みMVPアプリのAPIは https://mirai-board-audit-governance-preview.kensan1969.workers.dev/api で動作します。詳細契約は docs/api-contract.md。

エンドポイント一覧（主要）

カテゴリエンドポイント内容
認証POST /api/auth/login, GET /api/auth/meデモログイン（HMACセッション）
会議/api/meetings, convocations, attendance-events招集・出欠イベント
議案/api/agenda-items（CRUD＋状態遷移・COI・パッケージ・資格・議決・決議）取締役会フロー一式
議事録/api/meetings/:id/minutes/versions, /api/minutes/:versionId/signoffs版管理・二重記名拒否
履行/api/decisions/:id/actions, /api/actions/:id/eventsタスク生成・独立確認
監査/api/audit-universes, risk-assessments, annual-plans, engagements, procedures, workpapers, reviews, findings内部監査フロー一式（SoD強制）
証跡/api/manifests（一覧・詳細・verify）, /api/evidence-packages/:idEvidence Manifest・印刷用HTML
監査ログ/api/audit-events, /api/audit-events/verify-chain追記型チェーン・検証
検索・KPI/api/search, /api/dashboard/kpis権限対応検索・指標
保持/api/retention-rules, legal-holds, disposals法的保全・廃棄制御
AI/api/ai/drafts（生成・レビュー・保存・共有）出典必須・人レビュー
CSV/api/exports/agenda-items.csv ほか権限対応エクスポート

権限モデル

  • RBAC: director / kansa_yaku / secretariat / internal_auditor / internal_audit_manager / business_owner / legal / records / admin / audit_log_viewer
  • ABAC: 議案の閲覧・審議・議決・通知はCOI判定の操作別制御を参照
  • 職務分離: 調書の作成者≠レビュー者、申請者≠承認者、回答者≠再検証者（サーバ強制）
  • 認可拒否は404（存在非露出）。全エラーに相関ID

WebUIデモ機能（サーバーAPI化はバックログ）

  • CSV / Excelインポート（議案・指摘・ユーザーの一括登録）: モックアップ内でクライアント処理
  • システム設定（ユーザー・グループ・ロールの追加・編集・削除）: モックアップ内でlocalStorage永続化
  • AI設定（モデル選択・出典必須・人レビュー必須・機密マスキング・保存上限）: モックアップ内で適用
